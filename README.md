# Flappy Bird Clone

A simple 2D mobile game developed in Unity using C#.

## About the Game

Flappy Bird Clone is a 2D arcade game where the player controls a bird and tries to pass through obstacles without hitting them.

## Features

* 2D player movement
* Tap-based controls
* Obstacle system
* Collision detection
* Score system
* Game over system
* Restart functionality
* Sound effects

## Technologies

* Unity
* C#
* Unity 2D Physics

## My Role

Designed and programmed the gameplay, player controls, obstacle system, collision detection, scoring, and game logic.
